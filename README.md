# 石材大板排版对纹工作台

浏览器内的天然石材大板排版与对纹预览系统。TypeScript + Vue 3 + 原生 WebGL2（自写着色器，无 three.js），数据本地化存储在 IndexedDB。

## 启动

```bash
pnpm install
pnpm dev        # 开发服务器 http://127.0.0.1:5180
pnpm build      # 类型检查 + 生产构建
pnpm typecheck  # 仅类型检查
```

开发期可访问 `http://127.0.0.1:5180/selfcheck.html` 运行 WebGL 运行时自检（11 项，覆盖着色器编译、排样、对纹、3D 网格、导出）。

## 页面与功能

| 页面 | 能力 |
| --- | --- |
| 大板库 | 照片入库（四点透视校正 + 白平衡/曝光/色温）、程序生成大理石/石英岩纹理、实际尺寸/厚度/缺陷区/板边留量 |
| 项目列表 | 项目与客户管理，按厨房/客厅/卫浴分类 |
| 面编辑 | 台面/岛台/背景墙，开孔（台盆/灶具/龙头/自定义）、四边倒角、下垂边、三种表面处理 |
| 排版编辑 | Max-Rects 自动排样、多板续板、手动平移/旋转/镜像、缺陷区与留量实时约束校验 |
| 对纹检查 | 书本对纹/连续对纹，缝两侧纹带 NCC 模板匹配，输出错位像素与置信度 |
| 方案对比 | 多方案按利用率/违规/对纹质量综合评分并排比较 |
| 渲染预览 | 真实尺寸 3D 台面，顶/侧/下垂边纹理物理连续，亮光/哑光/荔枝三种 BRDF |
| 设置 | 对纹阈值、工作纹理分辨率、留量、网格、主题等 |

导出：切割图 DXF（R12，CAD 可直接打开）、渲染图 PNG、用料清单 CSV（带 BOM，Excel 中文不乱码）。

## 核心设计

### 对纹精度（硬指标 < 1 像素）

所有纹理映射走毫米物理坐标系：纹理坐标 = 物理点在大板上的毫米位置 ÷ 板尺寸。JS 端不做任何像素级贴图坐标运算，旋转平移只通过 uniform 传入着色器。同一块板切开的相邻件，缝两侧采样点物理位置一致，GPU 浮点误差远小于一个纹理像素。

`src/core/precision_test.ts` 实测：3200mm 大板、4096 工作纹理下，同板切开拼回的缝两侧错位为 **0.000 纹理像素**。

错位量化通过离屏 FBO 采样缝两侧纹带 + 归一化互相关（NCC）模板匹配，输出平移量并按 `pxPerMm` 折算像素。

### 8K × 4 流畅拖动

- 编辑视图使用工作纹理（默认最大边 4096，受 `MAX_TEXTURE_SIZE` 约束自动降档），原始 8K 照片存 IndexedDB，导出才全分辨率采样
- 纹理统一转 2 的幂尺寸并生成 mipmap + 各向异性过滤，非 POT 自动重采样
- 拖动只更新 uniform 重绘，零纹理重新上传
- 纹理池带 LRU 显存回收（默认上限 1.5GB）

### 三种表面处理

片元着色器内按 finish 分级：亮光面低粗糙度强镜面、哑光面高粗糙度弱反射、荔枝面高频微凹凸扰动 + 漫反射为主。

### 侧边/下垂边纹理连续

3D 网格的顶、侧、下垂边顶点共用同一套「大板毫米坐标」属性，侧边纹理坐标沿法线方向平移物理距离，纹路从正面连续走到侧边，不是独立贴图拉伸。

## 目录结构

```
src/
  core/            纯逻辑：几何、类型、排样、约束、对纹、导出、照片校正
  render/          WebGL2：上下文、纹理池、程序纹理、2D/3D 渲染器、缝采样
  stores/          Pinia：大板、项目、方案、设置
  views/           页面
  components/      通用 UI 与业务组件
  selfcheck.ts     运行时自检（不进生产路由）
```

## 已验证的关键缺陷修复

- SAT 碰撞检测把「共边贴合」误判为重叠（严格小于号 + epsilon 修正）
- 跨 program 设置 uniform 触发 GL 1282（bindCamera 内先切换 program）
- FBO 离屏纹理未解绑即删除，污染后续 bindTexture 状态
- 非 2 的幂纹理开 mipmap 在严格驱动下非法（上传管线统一 POT 化）
